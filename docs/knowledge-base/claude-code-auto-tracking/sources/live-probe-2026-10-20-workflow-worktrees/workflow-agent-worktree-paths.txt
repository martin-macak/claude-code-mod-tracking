# Workflow agent worktree names against the agents of four saved runs. Command outputs, nothing else.
# Captured 2026-10-20 for issue #120. Read-only. Changes to the output: the home folder is written as ~, and for run 2 only
# the last path part is kept. Prompts and agent results are not read.
# Each run lives in <session folder>/subagents/workflows/<runId>/. journal.jsonl has one "started" line for each agent, in
# the order the agents began. agent-<agentId>.meta.json has the worktreePath of the agent.
# Columns: position in the journal, label, worktreePath ("-" when the meta.json has none).
# Run in the folder of each run:
$ n=0; jq -r 'select(.type=="started")|[.agentId,.label]|@tsv' journal.jsonl | while IFS="$(printf '\t')" read -r id label; do n=$((n+1)); wt=$(jq -r '.worktreePath // "-"' "agent-$id.meta.json"); echo "$n $label $wt"; done | sed "s#$HOME#~#"
# The Claude Code version of each run is the "version" key of its agent transcripts:
$ for f in agent-*.jsonl; do jq -r '.version // empty' "$f" | head -1; done | sort | uniq -c
