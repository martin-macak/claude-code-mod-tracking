## 5. Requirement gaps found in review

The review compared the requirement with the research. These points are not settled by research. Most need a user answer (D13 to D17 above, plus D1 to D6).

- **"Created on top of parent branch".** Claude worktrees start from `origin/main` (or local `HEAD`), never from the session's branch, and all land flat under the main tree. Read literally, no Claude worktree qualifies. The user must pick a meaning (D2).
- **"Parent branch = current `pwd` of master session".** The `pwd` moves after `EnterWorktree`. Pin or follow (D13). The master session may also run inside a linked worktree (`claude -w`). Then the main tree and other linked trees are siblings, not children. The requirement does not say whether siblings show.
- **"Agents working on this branch or any worktree".** It does not say whether separate `claude` processes count. In-process subagents are exact. Separate processes need `ListAgents` (no `cwd`, all repositories), `claude agents --json` (a CLI call, N17), or store records (only peers that run the mod, only one config dir, N16). Scope is D3.
- **Teammates in their own pane** are separate processes too. Same route as other sessions.
- **"PRs on any tracked branch".** Which branches: the anchor's branch and every worktree branch (D6). Most Claude branches (`worktree-agent-*`) never get a PR, so most aliases return nothing. Stacked PRs (base = tracked branch) are untested (N8).
- **Interaction with manual tracking.** A discovered PR and a mentioned PR share one key and merge. A ref from a PR body needs provenance (`via`) and an eviction rule (D8). Dismiss is missing (D14).
- **Persistence.** Derived rows are recomputed (D11). Dismiss lists and PR-body refs need storage. The `/clear` id change must move the presence key.
- **Refresh cadence.** One 30 s tick per session. Many sessions multiply GitHub cost (D15, N18). A `claude -p` run never ticks.
- **Removal of stale items.** Worktrees, agents and PRs end at different speeds (D16).
- **UI layout.** The requested rows have three columns: name, branch, worktree. A docked pane body is 62 columns at a 140-column terminal. Claude branch names such as `worktree-agent-a94bdd45b56e2c631` take 32. A short label (`agent a94bdd`) and truncation rules are a design task.
- **Privacy.** Other sessions' names and paths show in the pane. Only metadata is read (D4).
