# Glossary

Terms of the mods API, alphabetical. Each row cites the source. Pinned to Claude Code 2.1.295.

| `.catch` | The one handler a registration takes. Runs when the hook throws, answers a wrong shape or overruns its budget. Its answer within the grace stands as the hook's result. `undefined` makes the hook absent. | [d.ts:9327](../sources/claude-code-2.1.295/types/claude-code.d.ts#L9327), [d.ts:1172](../sources/claude-code-2.1.295/types/claude-code.d.ts#L1172) |
| `$` (engine interface) | The first argument of every hook. The mod's only way to reach outside its isolated environment. Each call is spelled noun then method. | [d.ts:2315](../sources/claude-code-2.1.295/types/claude-code.d.ts#L2315), [skill:27](../sources/claude-code-2.1.295/SKILL.md#L27) |
| `--plugin-dir` | Flag that loads a plugin folder from disk for one session and hot-reloads it on save. | component | A name that has a render site: `AskUserQuestion`, `UserMessage`, `AssistantMessage`, `ToolUse`, `ToolResult`, `ToolGroup`, `ToolProgress`, `CommandOutput`, `Spinner`, `TurnDuration`, `InfoNotice`, `SessionMode`, `PromptHint`, `AbovePrompt`, `Pane`. | contract | The `types/index.d.ts` file named by `"types"` in `plugin.json`. Declares `PluginState` keys and any noun the plugin adds to `$`. `claude plugin validate` checks it. | [skill:15](../sources/claude-code-2.1.295/SKILL.md#L15), [ref:66](../sources/claude-code-2.1.295/reference.md#L66) |
| core (tier) | The engine's own behaviour. The last link. Below it `next` rejects. | [d.ts:12600](../sources/claude-code-2.1.295/types/claude-code.d.ts#L12600), [d.ts:6535](../sources/claude-code-2.1.295/types/claude-code.d.ts#L6535) |

| dev-mods folder | The session's mods folder where Claude writes a mod (`<dev-mods>/<session-id>/<mod>/`). Writing there raises the "Enable hot reloading for this session?" question. SKILL.md shows it under the active config directory. | [skill:9](../sources/claude-code-2.1.295/SKILL.md#L9), [skill:19](../sources/claude-code-2.1.295/SKILL.md#L19), [docs: create](../sources/code-claude-com-2026-10-09/mods/create.md#L28) |
| door | Field of a `session.append` event: the route a row came in by (`prompt`, `command`, `response`, `tool-result`, `tool-message`, `delivery`, `attachment`, `hook-context`, `note`, `compaction`, `notice`). Matchable. | [ref:139](../sources/claude-code-2.1.295/reference.md#L139) |

| event | A named point where Claude Code is about to act (`tool.call`, `prompt.submit`, `ui.render`, ...). Calls on `$` are events too. | [d.ts:3943](../sources/claude-code-2.1.295/types/claude-code.d.ts#L3943), [d.ts:6836](../sources/claude-code-2.1.295/types/claude-code.d.ts#L6836) |
| family (`StateFamily`) | A `PluginState` key that holds one value per `id` (per drawn row). Its reference needs `id`. `memberOf(family, e)` supplies it. | [d.ts:12009](../sources/claude-code-2.1.295/types/claude-code.d.ts#L12009) |

| gating hook | A hook at a site whose answer can refuse or replace what was asked (`tool.call`, `tool.check`, `prompt.submit`, `config.set`, `plugin.register`, ...). `claude plugin validate` lists each as `gating hook with .catch:` or `without .catch:`. | [ref:66](../sources/claude-code-2.1.295/reference.md#L66), [d.ts:9327](../sources/claude-code-2.1.295/types/claude-code.d.ts#L9327) |
| guard | A gating hook that fails closed: it carries a `.catch` that refuses where `next` was not called. | hook | A function `($, e, next)` added with `on(event, matcher?, hook)`. A streaming hook is an async generator. | [ref:11-24](../sources/claude-code-2.1.295/reference.md#L11), [d.ts:6771](../sources/claude-code-2.1.295/types/claude-code.d.ts#L6771) |
| hooks module | The one TS/JS file named by `hooks/hooks.json` `modules`. Exports `register(on, options)`. An ES module whatever its suffix. | [skill:13-14](../sources/claude-code-2.1.295/SKILL.md#L13), [ref:14](../sources/claude-code-2.1.295/reference.md#L14) |
| hooks worker | The thread that runs installed mods. If it crashes three times, every non-built-in mod unloads until `/reload-plugins` or a new session. | [docs: admin](../sources/code-claude-com-2026-10-09/mods/admin.md#L362) |
| hot reload | The engine reloads the hooks module when its folder changes (`--plugin-dir` folders, the dev-mods folder once the person enabled it). `register` runs again, `session.start` fires again, `$.state` and `$.store` stay. | [skill:19-21](../sources/claude-code-2.1.295/SKILL.md#L19), [ref:72-73](../sources/claude-code-2.1.295/reference.md#L72) |

| managed seat | The `prepend` or `append` tier, set by managed settings only. A plugin cannot name its own seat.
