Resolve an item by experiment or a newer source. Then move the answer into the right page. Where the answer matters for older readers, the item stays here marked **Answered** with a link, so the numbers stay stable.

Precedence when sources conflict: types file > bundled `reference.md` / `SKILL.md` > public docs > GitHub samples > inference.
